# AutoQuestion 0.4.0

这一版增加填空、简答和解答题，以及两端答案复制。

- 一屏可混合单选、多选、判断、填空和简答/解答，单次最多 10 道。
- 填空按空的顺序给出答案，数量必须匹配；简答、解答显示完整正文，保留必要步骤、公式和换行。
- Windows 和 Android 可选择答案文字、复制整题；填空可逐空复制，再自行粘贴到需要的位置。
- 保留多题分别展示、AUTO / DOM / Vision、手机小悬浮按钮、旋转和停止清理；截图不存相册。

下载安装包后沿用原有配置。Android 可直接覆盖安装同签名版本，无须卸载；Windows 完整解压后双击 EXE。主观题需要支持相应输入能力的模型；DOM 仅支持能可靠确定题型、题组和空数的页面，其余可由 AUTO 回退图片。

模型可能漏空、漏题或解答错误，请核对题意、材料、图形和答案。主观题字段校验不等于正确性校验。复制只在主动点击时发生，复制内容可能被系统剪贴板或历史保留，停止 App 不会清除系统剪贴板。

作为 Pre-release 提供安装测试；Android 尚未在用户小米真机验收。详见 [Android 使用说明](ANDROID.md)、[Windows 使用说明](WEB_UI.md) 和 [验证记录](VALIDATION_0.4.0.md)。
