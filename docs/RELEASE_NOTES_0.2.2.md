# AutoQuestion v0.2.2

这一版修复多个后台实例争用 F8 的问题，并把 App 改成独立桌面窗口。

- 双击 AutoQuestion.exe，直接打开 App，不再打开浏览器标签页。
- 点击右上角 × 会停止答题并退出，释放 F8 / ESC 和本机服务。
- 再次双击会唤起已有窗口，不会再启动第二份后台服务。
- 已保存的模型配置和 Windows 安全凭据继续使用。

下载 Windows x64 ZIP，完整解压并保留 _internal 文件夹。双击 AutoQuestion.exe，在配置页填模型与自己的 API Key，保存后启动；题目放到前台再按 F8。最小化保持运行，ESC 只停止本次答题，× 退出整个 App。

界面使用 Microsoft Edge WebView2 Runtime（多数 Windows 10/11 已有）；缺少时按微软官方说明安装。便携版未做代码签名，不要求管理员权限。已有同步模型请求在退出时会停止接收新任务，并等待当前请求返回或超时；保存的 Key 不会因关闭窗口被删除。

支持的题型、AUTO / DOM / Vision 和限制沿用 0.2.1，不提供自动点击、提交或所有网站兼容保证。自动验证使用临时配置、合成 Key 和 Fake 答案，不发送真实收费请求。0.2.1 及更早标签保持原样。
