# AutoQuestion 0.6.0（Windows）

这一版把电脑工作台缩小、简化，方便把屏幕留给题目。

- 可收成约 80×80 的置顶 AQ 方框，点击展开当前答案和解题说明。收起不会停止 F8，也不会因为新答案自动弹开。
- 工作台集中显示运行控制和答案，支持原有同屏混合题、整题/逐空复制和选中文字复制。
- 增加日间与深色主题；配置、浏览器配对和应用更新放在“模型与配置”，说明放在“开始使用”。图形界面不再展示离线 Demo 入口，命令行 Fake 仍可用于开发验证。
- 首选下载为包含 AutoQuestion.exe 的 Windows ZIP，完整解压后运行，不需要 Python。

本次仅更新电脑端。Android 继续安装原签名的 0.5.0 APK，手机不会因为 Windows 版本增加而误报升级。Windows 0.5.0 可从 App 内检查并安装本版，原配置保留。

这是 Pre-release。请核对模型答案；不同 Windows 桌面环境的显示与捕获行为需按 [使用说明](WEB_UI.md) 检查。验证结果见 [验证记录](VALIDATION_0.6.0.md)。
