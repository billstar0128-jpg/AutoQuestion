# AutoQuestion 0.6.0（Windows）

这是公开预发布版。完整解压下载的 ZIP 后双击 `AutoQuestion.exe`，并保留 `_internal` 文件夹。[GitHub Release 与校验文件](https://github.com/billstar0128-jpg/AutoQuestion/releases/tag/v0.6.0)

- 工作台可收成置顶 AQ 方框，点击展开参考答案及解题说明。收起后 F8 仍可使用。
- 支持日间和深色主题、同屏混合题、整题及逐空复制和选中文字复制。
- 模型配置、浏览器扩展配对和更新集中在“模型与配置”。Windows 0.5.0 可通过应用内入口升级，保留已有配置。

此版本只更新 Windows。Android 版本及下载见[项目首页](../README.md)。Windows 操作及捕获限制见[使用说明](WEB_UI.md)。
