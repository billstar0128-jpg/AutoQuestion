# 紧凑工作台与下载入口

用户要求电脑界面不遮挡题目、可切换日间/深色、简化工作台、移除离线 Demo 邀请，并让 GitHub 下载优先获得含 EXE 的包。补充要求：方框稍大，点击可看答案与思路并复制。

实现选择：继续使用现有本机 WebView2 和同源鉴权 API，常规答案窗可缩放，收成约 80×80 的置顶 AQ 方框；点击仅展开当前答案，F8 继续读取前台题目，不因新答案抢焦点。原有浏览器 DOM、AUTO、主观题、多题及复制不变。原生窗口在捕获时排除自身，不能以黑框替代被遮题目；不支持系统排除时需安全隐藏/恢复自有窗口。

前端使用现有 HTML/CSS/JS；工作台只保留运行控制、当前结果和可折叠记录。模型配置、DOM 配对、更新与说明移到设置/使用页。移除图形入口离线 Demo，保留命令行 Fake 与测试夹具。明暗选择只保存非秘密界面偏好；不修改 Key 保存方式。

考虑过只降低最小尺寸（仍遮挡题目）和新建独立原生答案窗（增加同步与生命周期复杂度）；采用同一窗口的收起/展开模式。普通浏览器只提供响应式布局，不声称网页能覆盖其他桌面应用。

Windows 版本 0.6.0；手机本轮不改功能，下载仍指向已发布 0.5.0 APK。GitHub 内置 Code→Download ZIP 仍是源码，无法改为程序；README 首屏与网站主下载按钮明确直达含 EXE 的 Windows ZIP。保留历史标签和 Pre-release 状态，版本更新继续从固定仓库校验下载。
