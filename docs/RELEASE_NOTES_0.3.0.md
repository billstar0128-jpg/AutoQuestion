# AutoQuestion 0.3.0

这一版补上同屏多题和 Android 悬浮识题。

- 单选、多选、判断题可以混在同一屏，最多识别 10 道完整可见题，分别显示题干、答案与理由。
- 三到六道混合题已加入自动测试。Windows 新配置默认等待 180 秒，可调到 300 秒；旧配置保留原值。Android 读取等待 180 秒，分析中可停止。
- Windows Vision 一张图一次请求；DOM 按题组获取并逐题验证，整批完成后显示。原来的 F8 / ESC、AUTO 回退和关闭窗口退出继续保留。
- Android App 在其他应用上方显示可拖动的小方框，点击识题，展开查看各题答案；可从通知或主界面停止。
- 截图仅在内存中处理，不写入相册。手机 API Key 使用 Android Keystore 加密，直接请求自己配置的 HTTPS 模型服务。

下载本页的 Windows ZIP 后完整解压、双击 EXE；Android 下载 APK 安装，设置模型和 Key，再按界面授权悬浮窗与屏幕共享。无需自己的服务器。

限制：手机必须用支持图片的模型；只处理当前可见完整题，不滚动、不勾选、不提交。受保护页面可能黑屏，部分小米权限和后台策略需手动允许。模型仍可能漏题或答错，请核对结果。Android 尚未在用户的小米真机验收。

本次作为 Pre-release 发布，方便先测试首版 Android App。已有 0.2.x 标签和安装包保持原样。

安装和验收步骤见 [Android 使用说明](ANDROID.md)、[Windows 使用说明](WEB_UI.md)；测试记录见 [0.3.0 验证记录](VALIDATION_0.3.0.md)。
