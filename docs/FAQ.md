# 常见问题

这份说明适用于 GitHub 已发布的 Windows 0.6.0 和 Android 0.6.1。下载入口见 [README](../README.md)。

## 装不上，或打开后没有窗口

- **在 Windows 上**，右键点下载的 x64 ZIP，选“全部解压”，保留同目录的 `_internal`，再打开解压后的 `AutoQuestion.exe`。便携包可直接用普通用户权限运行。若提示缺少 WebView2，请按微软说明安装运行时。 [Microsoft WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)
- **如果 Windows 提示未知发布者**，请核对下载来源和 SHA-256。便携包未做商业代码签名。请从本项目的 GitHub Release 下载，并用该发布页的 `SHA256SUMS.txt` 核对文件。公司或学校管理的设备请遵守设备管理员的安装规则。
- **在 Android 8.0 或更新版本上**，打开 APK 后按系统提示授权安装来源。如提示与已安装应用冲突，先核对现有包是否来自同一项目。卸载应用会清除本地配置。 [Android 使用说明](ANDROID.md)

## API Key、Base URL 和模型怎么填

Windows 在“模型与配置”中保存，Android 在首页保存。API Key 从模型服务商的控制台创建。Base URL 填服务商的 API 根地址，应用会补上 `/chat/completions`。模型 ID 以服务商文档中的拼写为准。Android 和 Windows 的图片识别需要模型支持 Chat Completions 的 `image_url` 输入。Windows 还要在确认模型支持后勾选图片能力。

保存只检查输入格式。首次识题前请确认 Key 有权限、账户可用且允许计费。Android 保存后会清空 Key 输入框，同一服务地址下留空保存可保留已存 Key。获取 Key、充值和模型示例见 [API 配置指南](API_SETUP.md)。

## 为什么识别失败或答案不完整

1. **如果系统没有响应识题操作**，Windows 先点“启动答题”，再把题目窗口置于前台并按 F8。捕获时请保持窗口和浏览器标签稳定。Android 先开启悬浮识题，再轻点题目页上的 AQ，按提示确认共享。
2. **如果图片看不清或题目漏识**，放大题目，使题干、选项和必要图表完整可见，再手动触发。单次最多处理 10 道完整题，多页题目可逐屏处理。
3. **如果请求被拒绝**，核对服务商控制台的 Key 权限、余额、Base URL 和 Model ID。如果使用图片，确认模型和接口支持图片输入。
4. **如果超时或模型返回格式无效**，检查网络，缩小题目范围，等当前请求结束后再试。Windows 可停止识题后调高“模型等待时间”并保存。答案和置信度由模型给出，请对照原题核查。

## Android 为什么返回黑屏或没有画面

先切回普通练习页面，保持屏幕点亮，轻点 AQ 并确认系统屏幕共享。系统允许选择共享范围时，请选题目所在应用或整个屏幕。银行、密码、DRM 内容或主动限制截屏的页面可能返回空白或黑屏，应用遵守系统保护。

系统正在录屏时，Android 11 及以上可启用 [录屏兼容](ANDROID.md)。如果服务尚未连接，回系统无障碍设置检查，或结束录屏后用普通屏幕共享重试。悬浮球没出现时，回系统设置确认 AutoQuestion 获准在其他应用上层显示。

## 为什么 Windows 从 DOM 回退到截图

“AUTO”会尝试从已配对、已授权且位于前台的 Chrome / Edge 提取可见题目文字。扩展未连接、站点未授权、页面用 Canvas 或图片绘制题目，或浏览器限制访问页面时，AUTO 会尝试对同一目标使用图片识别。先检查扩展配对、页面授权和前台标签。桌面应用通常直接走图片识别。

严格 DOM 模式会在取题失败时提示错误，适合只允许发送结构化题目文本的场景。AUTO 在图片能力未配置时会拒绝截图请求。模型调用出错时也不会触发图片回退。安装和授权详见 [浏览器扩展说明](BROWSER_DOM_SETUP.md)。

## 截图、题目和 API Key 发到哪里

题目文字或图片直接发到你配置的模型服务地址，模型服务商可能按其条款留存请求。截图只在应用内存中处理，发送前请移开个人信息、通知和无关窗口。Windows 可选择用系统安全凭据保存 Key 或仅本次使用，Android 使用系统密钥存储加密。主动复制的文字可能留在系统剪贴板或历史中。详见 [隐私说明](../PRIVACY.md)。

请在自己的题库、非计分练习或获准的场景使用。应用只展示答案和解题说明，提交和粘贴由你自行操作。

## 怎样更新应用

Windows 在“模型与配置”的“应用更新”中检查，Android 在首页的“应用更新”中检查。发现更高版本后，由你点击下载和确认安装。检查只读取本项目的 GitHub Releases，也会查看已公开的预发布版本。没有可用包或 GitHub 无法访问时，仍可用原版本。0.4.0 及更早版本请从 Release 手动下载新版。

- **Windows** 安装并重启后用桌面快捷方式进入新版。旧的便携目录里的 EXE 仍对应旧版。源码运行请手动更新源码或下载新版便携包。
- **Android** 覆盖安装需要相同包名、相同签名及更高版本。需要手动更新时，从本项目的 Release 下载较新的 APK，按提示覆盖安装。
