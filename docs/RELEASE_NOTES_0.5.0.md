# AutoQuestion 0.5.0

这一版增加两端的应用更新入口。

- 启动、返回前台及前台每 15 分钟检查公开 GitHub Releases，包含已发布测试版。只选择比当前更高的可校验版本，不按发布时间或字符串顺序判断。
- 点击下载后验证大小和官方 SHA-256；有 `SHA256SUMS.txt` 时验证并交叉核对，失败不安装。
- Windows 先停止答题，再点击安装并重启；新窗口确认启动后更新桌面快捷方式，旧版本和配置保留。源码运行只提供手动下载入口。
- Android 下载后还验证 APK 包名、版本和同签名，由用户在系统界面确认安装；不会静默更新。更新下载期间需留在主界面，后台悬浮识题不检查更新。

0.4.0 及更早版本没有更新模块，需要先手动下载并安装本次版本。Android 使用同签名 APK 覆盖安装，不用卸载；Windows 完整解压后运行，原有 AppData 配置保留。

同屏多题、单选、多选、判断、填空、简答/解答及答案复制继续保留。模型可能漏题或答错，不能用字段校验代替人工核对。

版本请求不附带模型 Key、题目、答案、截图或本机会话令牌，但 GitHub 会收到普通 HTTPS 请求信息。离线 Demo 不调用模型，App 的自动检查仍会访问 GitHub；断网或检查失败不会阻止预置 Demo 和原有答题。

本次仍作为 Pre-release 验证，不代表用户小米真机已经通过验收。最终结果见 [验证记录](VALIDATION_0.5.0.md)。
