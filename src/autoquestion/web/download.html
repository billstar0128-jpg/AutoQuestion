3 STEPS TO START

从下载，到第一道题。

01

下载并完整解压

上方主按钮直接下载含 EXE 的程序包。右键“全部解压”，保留 _internal 文件夹。GitHub 的 Code → Download ZIP 是源码，普通使用请选程序包。

02

双击 AutoQuestion.exe

独立 App 窗口会打开。无需安装 Python，无需终端命令。

03

配置、启动、按 F8

填好自己的 API 配置并保存。启动后把题目窗口放到前台，按 F8；ESC 停止答题，右上角 × 退出 App。再次双击唤起已有窗口。
