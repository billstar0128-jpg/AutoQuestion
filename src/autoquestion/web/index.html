FROM ZERO TO F8.

第一次用？从这里开始。

一次准备，之后双击就能打开。

01

下载到 Windows 电脑

下载 Windows x64 便携 ZIP 并完整解压。保留 _internal 文件夹，不需要安装 Python。

下载 Windows App ↗
02

双击 AutoQuestion.exe

浏览器会自动打开本机工作台。无须安装依赖，也不需要 PowerShell。

源码用户仍可使用 AutoQuestion.pyw；便携 App 直接运行 EXE。

03

配置模型，启动答题

在“模型与配置”按示例填 URL、模型和 Key。需要读桌面截图时，确认模型支持图片输入。

04

题目置前台，按 F8

支持单选、多选和判断。不要让工作台自己成为要分析的前台题目。ESC 停止服务，界面可以重新启动。

输入方式怎么选？

AUTO
受支持网页先 DOM，桌面直接 Vision。取题失败时回退 Vision。
DOM
只读已配对浏览器或受管理 Demo，失败报错。
Vision
始终读取前台窗口截图，需要图片模型。
离线 Demo
预置合成示例，不代表真实模型能力。
